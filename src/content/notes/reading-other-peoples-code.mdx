Tutorials flatten the mess. Production code keeps the mess and gives it names.

When I am stuck, I read a module I did not write and ask: what was this person afraid of? The extra branch, the oddly specific type, the comment that is slightly bitter (or suspisciously obvious). These are usually the real design document.

This is more tedious than watching a video. It is also closer to the actual job.
